# Onboarding domain knowledge

Reference corpus for the onboarding coordinator (goal `employee_onboarding_ready`).

- `coordinator-playbook.md` — coordinator owns employee_onboarding_ready; delegates outcomes, never domain actions; escalation and verdict rules.
- `required-workflows.md` — profile-to-required-outcome mapping and the `workflows` context override.
- `hitl-policy.md` — when the coordinator opens human tasks and who resolves them.
