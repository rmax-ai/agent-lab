# Access escalation

If a manager approval never arrives within the human-task SLA, escalate to
the onboarding coordinator by reporting a blocker; do not proceed without
the approval.

If a request is denied and the denial conflicts with the employee's role,
report a blocker and involve the onboarding coordinator and the manager.

Unresolvable access blockers are escalated through the workflow: report the
workflow blocked (or failed) with a machine-readable blocker code rather than
improvising a workaround.
