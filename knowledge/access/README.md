# Access domain knowledge

Reference corpus for the access agent (goal `employee_access_ready`).

- `standard-access-policy.md` — baseline group access and the verify-not-request rule.
- `privileged-group-approvals.md` — manager-approval flow for privileged groups.
- `request-resolution.md` — how access requests resolve (approved, denied, pending).
- `exceptions.md` — intern and contractor handling.
- `escalation.md` — when to escalate access blockers upward.
- `unknown-employee.md` — how to handle an employee the world does not know.
