# Device domain knowledge

Reference corpus for the device agent (goal `employee_device_ready`).

- `standard-device-policy.md` — default hardware for engineering hires and the substitute-confirmation rule.
- `location-policy.md` — how office location affects hardware and delivery, and address-confirmation rules.
- `inventory-substitution.md` — substitution tiers and approval rules when a required SKU is unavailable.
- `replacements.md` — how defective or wrong-delivery devices are replaced.
- `escalation.md` — when to escalate inventory or delivery problems upward.
- `exceptions.md` — intern and VP-level exception handling.
