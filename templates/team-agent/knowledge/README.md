# Team knowledge

Put your team's Markdown knowledge documents in this directory.

Each document uses simple frontmatter followed by a Markdown body:

```markdown
---
title: Document title
owner: Team name
status: active
updated: YYYY-MM-DD
---
# Body

Policy content here.
```

See `knowledge/devices/` at the repository root for full, working examples and
for how the Device agent references its corpus.
